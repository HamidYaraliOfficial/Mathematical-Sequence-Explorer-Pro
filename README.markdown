# Mathematical Sequence Explorer Pro

---

## English

### Overview
**Mathematical Sequence Explorer Pro** is a **powerful, elegant desktop application** that brings **12 famous mathematical sequences** to life with **stunning visuals**, **real-time generation**, **mathematical properties**, and **multilingual support**.

Built with **PyQt6** and **pure Python**, this professional-grade tool is designed for **mathematicians, educators, students, and developers** who want to **explore, analyze, and export** sequences like **Fibonacci**, **Lucas**, **Pell**, **Triangular**, **Primes**, and more — all in a **modern, responsive interface**.

---

### Key Features
- **12 Built-in Sequences**:
  - Fibonacci • Lucas • Pell
  - Triangular • Square • Cube
  - Factorial • Catalan • Harmonic
  - Prime Numbers • Collatz (3n+1)
  - Custom Linear Recurrence
- **Real-Time Generation** up to **1,000 terms**
- **Mathematical Properties Panel**:
  - Recurrence relation
  - Closed-form formula
  - Sum of first n terms
- **Multilingual Interface**:
  - English • Persian (فارسی) • Chinese (中文) • Russian (Русский)
  - Full **RTL layout** support
- **8 Stunning Themes**:
  - System • Light • Dark
  - Crimson Fire • Ocean Depth • Emerald Forest
  - Amethyst Glow • Sunset Blaze
- **Professional UI Design**:
  - Gradient headers
  - Rounded corners
  - Smooth hover effects
  - Windows 11 aesthetic
- **Export & Copy**:
  - Save to `.txt`
  - Copy to clipboard
- **Custom Recurrence** with user-defined seeds
- **Responsive & Scalable** layout

---

### Requirements
- Python 3.8+
- PyQt6

---

### Installation
1. Install PyQt6:
   ```bash
   pip install PyQt6
   ```
2. Save the script as `math_sequence_explorer.py`
3. Run:
   ```bash
   python math_sequence_explorer.py
   ```

---

### Usage
1. Choose **language** and **theme**
2. Select a **sequence type**
3. Set **number of terms** (1–1000)
4. For **Collatz** or **Custom**, enter **start value**
5. Click **"Generate"**
6. View **sequence output** and **mathematical properties**
7. Use **"Copy"** or **"Export"** to save results

> **Pro Tip**: Try the **Collatz sequence** with different starting values to observe convergence patterns.
